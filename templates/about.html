About the PMH Call Scheduler

What this tool does

This application builds monthly call schedules using Google OR-Tools (CP-SAT solver). It balances hard rules (must be respected) and soft preferences (try to satisfy) to produce a fair and practical rota.

Key logic and rationale

  • Hard constraints: Minimum rules the schedule must satisfy — for example:
    • Level-2 supervision structure (2A/2B logic) as configured.
    • Forbid impossible assignments (NLTH rules, domain pruning by availability).
    • Force critical roles on weekends/holidays (e.g., 1B) when enabled.
  • Soft objectives: Fairness and preferences, weighted by sliders in Global Config / Constraint Weights — for example:
    • Overall fairness: equalize total calls across surgeons.
    • No‑call and unavailability penalties: discourage violating requests.
    • Spacing: avoid calls too close together for the same person.
    • Weekend fairness and team diversity: spread weekend load and teams.
    • Unavailability credit: each N days off reduces expected calls.

How to use

  1. Go to Surgeon Management to review/maintain surgeon list, levels, and teams.
  2. Use Availability to record unavailability and no‑call requests.
  3. Optionally set Preassignment for fixed assignments in a month.
  4. Open Global Config and/or Constraint Weights to tune constraint toggles and weights. Sliders show live values; helper text explains each control.
  5. Go to New Schedule:
    • Select year/month.
    • Click Generate (30s) or Generate (120s). The solver will search for a good solution within the time limit.
    • When done, review the table. You can Save the schedule for the selected month.
  6. Use Export buttons to download the schedule or requests matrix (unavailability / no‑call) in Excel format.

Tips

  • If results look imbalanced, increase fairness/spacing sliders a bit and re‑run.
  • If feasibility is hard to achieve, relax/disable some toggles temporarily (e.g., consecutive‑weekend penalty) and try again.
  • Increasing the time limit (120s) usually improves solution quality.

This page is informational only; you can change settings in Global Config and Constraint Weights.
